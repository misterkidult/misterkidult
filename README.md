## 正在打造

- **Personal FDE：自己就能完成的 Agent 工作流**：FDE 是 Forward Deployed Engineer，直接進到使用者現場、陪著把事情做成的工程師。Personal FDE 把我這套作業系統裡反覆用到、確定有效的做法，一項一項整理成可以單獨安裝的功能，例如分出專職助理、交件前多一關審查、你沒在看的時候定時巡一輪。第一項「分帳」已經做好，每則回應分成給你讀的話和留給日後回查的紀錄；其他功能陸續整理中。
- **[ai-onboarding-starter](https://github.com/misterkidult/ai-onboarding-starter)**：AI OnBoarding 啟動包，也是 Personal FDE 的基本版。兩個檔案放進空資料夾，跟助理說「幫我啟動」，它會問你六個關於工作的問題，再陪你做一件手上真的要做的事，大約 30 分鐘，資料夾裡就有一套照你習慣寫的工作規則。支援 Claude 桌面版與 Codex，目前是 v11；說一句「檢查更新」就能升版，你自己長出來的規則不會被改。

- **[ai-nomos](https://github.com/misterkidult/ai-nomos)**：由真實用法長出來的 AI 詞典。人給文章連結和想撈的詞，agent 自己去讀、判斷、補上人沒列的，每則紀錄都附來源。OpenAI WebMCP Challenge 參賽作品。[打開字典 →](https://ai-nomos.vercel.app)

## 我怎麼用 AI

- **AI 是放大器。** 用 AI 做人本來就會做的事，差別在可以重複。它放大對的，也一樣放大錯的，所以先把一份改對，再展開成很多份。
- **AI 的答案是平均值。** 平均值讀起來永遠合理，所以天花板感覺不到。要超過平均，靠使用者在那個領域自己的判準。
- **對話要變成文本。** AI 每次對話都從零開始。上一輪講清楚的判斷有沒有寫下來、變成下一輪的起點，決定了長期的品質。
